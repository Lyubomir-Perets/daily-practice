# daily-practice

Small, focused coding reps while im in school
Goal: code almost every day, push often, and track growth

## Structure
- 'algorithms/' - data sttuctures, leetcode-style problems, math utilities
- 'systems/' - C + RISC-V, low-level / OS-Style Practice
- 'games-and-fun/' - experiments, toy scripts, game prototypes
- 'notes/' - logs of work, ideas, and TO-DOs

## Routine
1. Pick up small problem (15-80 lines)
2. Implement in a language
3. Run and verify that it works
4. 'git add', 'git commit', 'git push'.
